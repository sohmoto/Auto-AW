# Research Reports

このディレクトリには、GitHub Issueから開始された調査の成果物を保存します。

## ファイル名

```text
YYYY-MM-DD-issue-<Issue番号>-<短い英数字スラッグ>.md
```

例:

```text
2026-09-20-issue-12-github-agentic-workflows.md
```

スラッグには小文字の英数字とハイフンだけを使用します。

## 必須構成

各レポートには次を含めます。

1. タイトル
2. 調査概要
3. エグゼクティブサマリー
4. 依頼内容と採用した前提
5. 調査計画と調査方法
6. 詳細な調査結果
7. 比較表または論点整理
8. 情報源間の相違
9. 不確実な点・未確認事項・調査の限界
10. 結論
11. 推奨される次のアクション
12. 出典一覧
13. 調査情報

## 出典

- 一次情報と公式資料を優先します
- 資料名、発行主体または著者、公開日または更新日、URLを記録します
- 重要な主張は、可能な限り複数の独立した情報源で確認します
- 検索結果の要約だけを最終的な根拠にしません
- 確認できなかった情報や矛盾する情報を明記します

## レビュー

レポートはDraft Pull Requestとして提出されます。内容と出典を人間が確認した後にマージしてください。
